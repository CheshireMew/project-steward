# 布局、集合与响应式

用于处理空间比例、媒体构图、重复内容集合、真实可视窗口、一屏适配和跨视口重排。

## 1. 从职责分配空间

先确定第一焦点、第二焦点和辅助层，再分配主要内容区、信息区和操作区。每个空区承担聚焦、阅读、导航、状态或互动职责；没有职责的空栏、面板和边框重新分配。

容器只有承担分组、裁切、状态、命中或表面层级时才成立。卡片不是默认答案，单张卡片不能脱离整个集合单独获得一个“看起来合适”的尺寸。

局部空间优化以整个可见区域为预算，而不是只测被点名的条目。先记录内容、固定操作、模式切换、状态提示、间距和滚动各占多少，再比较修改前后的首屏有效内容数量、操作可达性和视觉重量。新增控件也消耗同一预算；如果新入口抵消了内容区节省的空间，方案尚未满足空间目标。

## 2. 让真实素材与界面共同构图

记录源素材比例与分辨率、主体位置、完整范围、第一焦点、可裁切区域、负空间、页面职责和本轮使用决定。

媒体预览同时区分四层几何：

```text
源内容范围与自然比例
→ 正式输出契约的宽高与裁切决定
→ 渲染表面的逻辑尺寸、显示缩放与物理像素
→ 布局容器的可用宽高、对齐和空间所有者
```

源内容完整不表示渲染表面没有裁切，渲染表面尺寸正确也不表示布局容器比例合适。正式输出契约已经提供比例时，布局不能再维护一份无来源的固定比例；渲染到原生表面时，逻辑尺寸与组合缩放应在唯一边界转换成物理尺寸，并在容器尺寸或显示缩放改变后重新计算。

主体、环境、光线和动作必须作为完整画面成立时，版式顺着整幅素材组织；不同视口需要大幅改变主体位置、背景结构或信息密度时，考虑分层素材或独立裁切版本。不能只用 `cover` 或 `contain` 代替设计判断。

用户要求完整展示的关键范围是硬合同。既不能为了铺满裁掉关键内容，也不能为了保全全部像素留下无职责空间。

### 面向后续动画的首帧建立运动空间合同

静态图片会作为视频、角色动作、镜头推进或其它时序媒体的首帧时，不能只检查当前轮廓是否完整。开始生成或裁切前记录：

```text
当前完整轮廓与必须保留的身份特征：
预期动作的起势、方向和最大运动范围：
手臂、翅膀、尾巴、衣摆、头发、道具和特效各自的运动包络：
四周安全区与最终消费者可能遮挡的区域：
主体目标面积、视觉重量和允许的镜头变化：
可以离开安全区的非关键粒子：
第一帧怎样保留继续运动的张力，而不是已经完成动作：
```

画幅变宽后要重新判断主体面积和视觉重心，不能只增加背景让角色显得过小；为了让主体更大，也不能再次压掉动作所需空间。首帧优先使用重心、视线、肢体方向和局部特效已经指向下一动作的蓄势状态，不把所有角色统一成同一种正面站姿或同一镜头角度。辅助物和特效只占用有身份或动作职责的区域，不能均匀围满主体并侵占运动包络。

标题栏、导航、状态提示或固定操作被合并、移除或压缩后，释放的空间不会自动成为媒体的合理高度。重新计算同屏各区域预算，并重新检查媒体容器、实际内容矩形和相邻操作；不能把上游空间优化后的第一次截图当作下游构图仍然成立的证据。

## 3. 重复内容先建立集合合同

```text
正式内容、稳定顺序和当前数量：
预计支持的数量范围：
固定行动与可变集合的相对位置：
主项、默认项和稳定排序来源：
每项比例、内容长度和必须完整显示的范围：
比较基准：等高 / 等宽 / 等面积 / 等信息密度 / 有意主次
裁切与压缩规则：
分行、分列、网格或轨道规则：
同组与跨组间距、允许和禁止遮挡：
选择、状态和行动的位置：
新增或移除后的重排：
```

集合存在随机推荐、本轮抽取、自动轮动或初始精选时，再把内容范围分成三个稳定职责：

| 范围 | 唯一职责 | 产生与重置 | 正式消费者 |
| --- | --- | --- | --- |
| 内容全集 | 决定产品真实拥有、允许浏览、搜索和直接访问的全部对象 | 只随正式内容增删或明确筛选改变 | 完整目录、搜索、深链，以及合同指定遍历全集的按钮、键盘、手势和辅助入口 |
| 本轮样本 | 决定当前会话或一次演示自动展示哪些对象及其顺序 | 只在合同指定的加载、重抽或会话边界生成 | 自动轮动、初始舞台和本轮进度 |
| 当前项 | 决定此刻的视觉焦点、说明、媒体和选择投影 | 所有选择入口通过同一稳定对象身份更新 | 主体、文案、读数、媒体、焦点和行动目标 |

抽样只改变本轮样本，不构成从内容全集移除其它对象的授权。手动入口遍历全集还是样本由当前产品任务明确决定；一旦确定，所有入口共同消费同一当前项，不能让自动轮动、左右按钮、键盘和深链各自维护索引。筛选会改变可访问集合时另建筛选合同，不能用抽样冒充筛选。首次打开、刷新、返回和恢复是否重建样本由互动生命周期合同决定，不由组件是否重新挂载偶然决定。

排布由正式内容、可用容器和目标视口共同产生，不按条目身份维护第二份坐标表。混合横竖比例、长短文案或不同密度内容时，同时比较最终宽度、高度、面积、对比和位置。

可变长度集合不能拥有固定主行动的可达性。一个行动无论条目多少都应立即可用时，把它放在集合之前、并列的固定操作区或明确的粘性区域；只有用户必须先读完或选择集合末项才能执行时，才把行动放在列表之后。至少用空集合、一个条目和超过首屏的真实数量验证，不能只在开发机当前条目数上看起来成立。

集合存在主项、首选项或系统默认项时，由正式内容投影提供同一排序和默认选择语义。首次打开、刷新、重新枚举和返回页面都应得到一致结果；不能依赖底层枚举偶然把主项放在第一位，也不能让视觉顺序与实际默认选择来自两套规则。

一次请求同时移动多个对象时，所有“稳定对象身份 → 目标位置”都相对于同一个变更前快照解释，禁止移动一项后立即重编号，再用已经改变的顺序解释下一项。先校验对象身份存在且不重复、目标位置有效且不冲突；再把移动对象放入各自目标位置，未移动对象按变更前的相对顺序填入其余位置。重复对象、重复目标位置或越界目标应在修改正式内容前报告冲突，不能留下半次重排。

```text
重排前稳定身份顺序：
同一快照上的对象 → 目标位置：
未移动对象的相对顺序：保持不变
正式最终顺序：
由最终顺序重新派生的序号、默认项、选择、读数、预热和其它消费者：
```

重排只改变正式顺序，不重建对象身份、复制素材或分别修补各个展示层。完成后，序号、默认项、当前选择、读数、预热列表、移动端轨道和其它顺序消费者都从同一最终顺序重新派生；不能让视觉卡片已经换位，而辅助读数或资源准备仍保留旧序号。

集合提供多种视图时，先定义共享的对象身份、顺序、搜索、筛选、选择、拖放和行动，再分别定义每种模式的预览尺寸、信息层级、列数、截断和空状态。模式切换器本身纳入同一空间预算；模式可以改变呈现密度，不能建立第二套内容或选择状态。

媒体集合的预览以“用户能否识别对象”为通过标准。图片使用保持内容可辨认的缩放图；视频优先显示靠前且已有可见内容的代表画面，而不是机械使用可能全黑、空白或尚未进入内容的起始时刻；无法生成时提供稳定的类型占位和文件身份。预览尺寸、裁切和清晰度随视图密度改变，但资源身份保持一致。

固定编辑式拼贴只在数量上限稳定、每个位置承担独立职责且其它视口有回退时成立。用户要求继续增加内容时，至少推演增加一项和两项后的分组、顺序、间距、滚动和操作可达性。

## 4. 使用真实内容视口

视口宽度与实际可视高度是两个独立输入。浏览器工具栏、书签栏、窗口标题栏、分屏、系统缩放、安全区域和软键盘都会压缩内容获得的空间，不能用显示器分辨率或窗口外框尺寸代替。

合同要求主要内容或操作一屏完整时，按以下顺序适配：消除冲突的最小尺寸，重算比例和锚点，收紧间距与字号，缩小媒体或面板，必要时改变分区。只有长文、列表、日志和明确的连续浏览内容获得滚动职责；用滚动条替代本应完成的一屏适配属于未完成。

## 5. 响应式是关系重排

先定义跨视口不变的内容层级、任务顺序、组件角色和选择状态，再定义空间变化。断点由内容关系何时失效决定，不由常见设备数字单独决定。

宽屏可以增加有效并列关系，窄屏先重排再缩小，低高度窗口可以改变分区。移动端可以把分组展平为轨道，减少动态效果模式可以改为静态网格；模式可以改变空间组织，不能建立第二套内容顺序和选中状态。

## 6. 几何验收合同

详细规格记录实际内容视口、固定区域、主要区域、关键媒体或卡片、必须一屏可见内容、页面与局部滚动职责。

实现后需要读取正式内容数量、自然比例、最终显示宽高与面积、分组顺序、同组与跨组间距、矩形交集、首末项可达性，以及选择、状态、切换器和行动的几何。多视图集合分别记录每种模式下的首屏条目数和切换控件占位。几何证明边界，截图证明层级、可读性和视觉重量；两者不能互相代替。

媒体问题还要分别记录布局容器矩形、原生渲染表面物理尺寸和最终内容矩形，并用正式素材执行播放、定位或其它实际消费动作。只测容器开始位置不能证明内容没有裁切，只看一帧也不能证明媒体消费者可用。
