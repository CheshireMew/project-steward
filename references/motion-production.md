# GitHub README 动画

只有用户明确选择 GIF，并且动画用于解释顺序、状态变化或关系时使用。它消费静态素材已经确定的视觉合同和语义图层，只决定运动，不增加卡片、容器、配色或装饰。静态 SVG 是可编辑源和回退；GIF 是 GitHub 中播放的发布格式。

## 1. 动作节奏

- 只移动解释概念所需的少数层，一到三个焦点通常足够。
- 进入距离约为画布尺寸的 `4–8%`，不让元素横穿整张图。
- 使用约 `0.7–1.2` 秒的平静 ease-out。
- 定格后留 `1.5–2.5` 秒阅读时间。
- 元素落定后保持像素静止；只有持续运动表达真实在线状态时才继续移动。
- 不逐个动画所有文字、图标和背景细节。
- 结尾回到第一帧状态，循环没有明显跳变。
- 避免闪烁、快速脉冲、弹跳和与阅读竞争的动作。

## 2. 默认参数

以下是起点，可以按实际素材调整：

```text
FPS: 30
时长: 4–6 秒
输出宽度: 通常使用 SVG 原生 1200px
颜色: 平面图从 192 色开始，复杂渐变或透明层使用 256 色
抖动: 平面颜色和文字使用 none
首选体积: 约 2 MB
实际警戒线: 5 MB
```

只有小文字确实需要且体积仍合理时使用 `1440–1600px`；小型嵌入或预览可用 `960px`。在最终 CSS 显示宽度比较，不以原始像素 100% 放大判断。

## 3. SVG 与运动规格

每个动画元素有稳定 `id`，字体和继承变换放在祖先组中。

在 SVG 旁建立 JSON：

```json
{
  "width": 1200,
  "fps": 30,
  "duration": 5.0,
  "colors": 256,
  "dither": "none",
  "clip_to_base_alpha": true,
  "max_size_mb": 2.0,
  "reveals": [
    {
      "id": "title-highlight",
      "axis": "x",
      "start": 0.25,
      "end": 1.25,
      "exit": {"start": 4.1, "end": 4.96}
    }
  ],
  "layers": [
    {
      "id": "primary-evidence",
      "enter": {"start": 0.4, "end": 1.3, "from": [72, -22]},
      "exit": {"start": 4.1, "end": 4.96, "to": [20, -10]}
    }
  ]
}
```

示例中的图层名只表示需要运动的主要证据，不规定它的形状。偏移量使用源 SVG 单位，渲染脚本按输出宽度缩放。移动层需要保持在静态素材已有的满幅表面内时使用 `clip_to_base_alpha: true`；有意透明镂空的素材保持关闭。

## 4. 渲染

脚本需要 Python、Pillow、`ffmpeg`，以及 `rsvg-convert` 或 macOS `sips`：

```bash
python scripts/render_motion_gif.py \
  assets/readme/hero.svg \
  assets/readme/hero.gif \
  --spec assets/readme/hero-motion.json
```

只有需要检查图层或单帧时增加：

```text
--keep-frames <新的空目录>
```

## 5. 控制体积和透明度

- 使用共享调色板和矩形差分帧。
- 优先使用 SVG 原生宽度或干净整数倍，避免任意缩放产生多余插值颜色。
- 平面素材从 `192` 色、无抖动开始；渐变和照片比较后再增加。
- 定格帧必须完全相同，既平静又容易压缩。
- 静态素材已有裁剪边界时，所有运动层使用同一边界，避免内容或装饰逸出。
- 渲染脚本使用未占用色键保存 GIF 透明度；素材可见区域已经使用该色时更换色键。
- 透明轮廓在循环中保持稳定。移动层放在不透明或裁切背景内，避免 GIF 解码残影。
- 全宽 hero 无法保持合理体积时，首屏使用静态素材，把较小 GIF 放到后面的演示区。

## 6. 验收

1. 检查进入、首次定格、完整阅读停留、退出和循环边界。
2. 证明定格帧像素一致，排除空闲抖动和渲染噪声。
3. 在 GitHub 内容宽度和窄屏查看。
4. 使用 `ffprobe` 核对帧数、FPS、时长、尺寸和体积。
5. 保留静态 SVG。
6. README 只有在用户授权嵌入后才切换图片引用。

交付 SVG、运动 JSON、GIF、体积和验收结果，然后返回当前 README 子类型。
